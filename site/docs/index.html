Using Sudan Atlas in your codeاستخدام أطلس السودان في برامجك

One package for Python and one for JavaScript, with the same data and identical results. They match Sudanese place names written any way, in Arabic or English, to official P-codes, and give you the names and boundaries of Sudan's 18 states, the Abyei PCA area and 189 localities.

حزمة لبايثون وأخرى لجافاسكربت، تستخدمان البيانات نفسها وتعطيان النتائج نفسها. تتعرّف الحزمتان على أسماء الأماكن السودانية بالعربية أو الإنجليزية مهما اختلفت طريقة كتابتها، وتربطها بالرموز المكانية (P‑codes) الرسمية، وتوفّران أسماء وحدود ولايات السودان الـ18 ومنطقة أبيي، ومحلياته الـ189.

Show examples inاعرض الأمثلة بلغة

Installالتثبيت

pip install sudan-atlas            # matcher, names and boundaries
pip install "sudan-atlas[geo]"     # adds GeoDataFrames (needs geopandas)
npm install sudan-atlas

Python 3.11 or later; Node 18 or later, or any modern browser. The place names, spellings and boundary files ship inside the package, so Python and Node work offline; in a browser the boundary files are fetched when first needed.

تعمل الحزمة مع بايثون 3.11 أو أحدث، ومع Node 18 أو أحدث، وفي أي متصفح حديث. وتأتي الأسماء وصيغها وملفات الحدود مضمّنة فيها، فلا تحتاج في بايثون وNode إلى اتصال بالإنترنت؛ أما في المتصفح فتُجلب ملفات الحدود عند أول حاجة إليها.

Your first matchمطابقتك الأولى

Give match a name as it appears in your data. It returns the official place, its P-code, a score from 0 to 1 and how it was matched.

مرّر إلى الدالة match اسم المكان كما ورد في بياناتك، فتُرجع المكان الرسمي ورمزه المكاني، ودرجة تطابق بين 0 و1، وطريقة المطابقة.

from sudan_atlas import match

match("Elfasher", level=2)
# {'pcode': 'SD02114', 'name_en': 'Al Fasher', 'name_ar': 'الفاشر', 'level': 2,
#  'score': 1.0, 'method': 'exact', 'alternatives': [...]}

match("الفاشر")["pcode"]      # 'SD02114'
import { match } from "sudan-atlas";

match("Elfasher", { level: 2 });
// { pcode: "SD02114", name_en: "Al Fasher", name_ar: "الفاشر", level: 2,
//   score: 1, method: "exact", alternatives: [...] }

match("الفاشر").pcode;        // "SD02114"

level is 1 for states and 2 for localities. Set it whenever you know it: "Kassala" is both a state and a locality, so match("Kassala") can't choose, while match("Kassala", level=1) returns SD11.

يحدّد level نوع المكان: 1 للولاية و2 للمحلية. ويُستحسن تحديده كلما عرفته، فاسم "Kassala" يُطلق على ولاية وعلى محلية في آن واحد، ولذلك لا تستطيع match("Kassala") الحسم بينهما، بينما تُرجع match("Kassala", level=1) الرمز SD11 مباشرة.

Your first mapخريطتك الأولى

Boundaries come as GeoJSON features in three detail levels: detailed, medium (the default) and light.

تأتي الحدود بصيغة GeoJSON وبثلاث درجات من التفصيل: detailed وmedium (الافتراضية) وlight.

from sudan_atlas import geo        # needs the [geo] extra

localities = geo.localities("SD02")            # North Darfur's 17 localities
ax = localities.plot(edgecolor="white", color="#2c7fb8")
localities.apply(lambda r: ax.annotate(r.name_en, r.geometry.representative_point().coords[0],
                                       ha="center", fontsize=7), axis=1)
import { getLocalities, getFeature } from "sudan-atlas";
import { geoConicEqualArea, geoPath } from "d3-geo";

const features = await Promise.all(getLocalities("SD02").map((p) => getFeature(p.pcode, "light")));
const collection = { type: "FeatureCollection", features };
const path = geoPath(geoConicEqualArea().parallels([9, 21]).rotate([-30, 0]).fitSize([600, 600], collection));
const svg = features.map((f) => `<path d="${path(f)}" fill="#2c7fb8" stroke="white"/>`).join("");

Add P-codes to a spreadsheetإضافة الرموز المكانية إلى جدول

Match each distinct name once, then join the result back. Keep the method and score columns so you can review the uncertain rows.

طابِق كل اسم مختلف مرة واحدة فقط، ثم أعِد النتائج إلى جدولك. واحتفظ بعمودي طريقة المطابقة ودرجتها لتعود إلى الصفوف غير المؤكدة وتراجعها.

import pandas as pd
from sudan_atlas import match

df = pd.read_csv("sites.csv")                     # columns: state, locality, people
results = {
    (loc, st): match(loc, state_hint=st, level=2)
    for loc, st in df[["locality", "state"]].drop_duplicates().itertuples(index=False)
}
df["pcode"] = [results[k]["pcode"] for k in zip(df.locality, df.state)]
df["match_method"] = [results[k]["method"] for k in zip(df.locality, df.state)]
df["match_score"] = [results[k]["score"] for k in zip(df.locality, df.state)]

df[df.pcode.isna()]       # rows to look at: no match, or a name that could be two places
import { match } from "sudan-atlas";

const cache = new Map();
for (const row of rows) {                       // rows: [{ state, locality, people }, ...]
  const key = `${row.locality}|${row.state}`;
  if (!cache.has(key)) cache.set(key, match(row.locality, { stateHint: row.state, level: 2 }));
  const r = cache.get(key);
  Object.assign(row, { pcode: r.pcode, match_method: r.method, match_score: r.score });
}
const toReview = rows.filter((row) => row.pcode === null);

Use a state hintتضييق البحث بالولاية

If your data has a state column, pass it. The matcher then looks only inside that state, which settles most look-alike names. The hint can be a P-code (SD15) or a state name in any spelling (Al Gezira, الجزيرة).

إذا كان في بياناتك عمود للولاية فمرّره إلى الدالة، فتبحث أداة المطابقة داخل تلك الولاية وحدها، وهذا يكفي لحسم معظم الأسماء المتشابهة. ويمكنك كتابة الولاية برمزها (SD15) أو باسمها بأي صيغة (Al Gezira، الجزيرة).

match("El Hasaheesa", state_hint="Al Gezira", level=2)["pcode"]   # 'SD15034' (Al Hasahisa)
match("Nyala Shimal", state_hint="SD03", level=2)["pcode"]        # 'SD03164'
match("El Hasaheesa", { stateHint: "Al Gezira", level: 2 }).pcode;   // "SD15034" (Al Hasahisa)
match("Nyala Shimal", { stateHint: "SD03", level: 2 }).pcode;        // "SD03164"

Handle uncertain namesحين لا تكون المطابقة مؤكدة

The matcher never guesses silently. When the best place scores below the threshold, or a second place scores almost as high, pcode is empty and alternatives lists the best three candidates for a person to choose from.

لا تخمّن أداة المطابقة أبدًا دون أن تخبرك. فإذا كانت درجة أفضل مكان أقل من الحد المطلوب، أو اقترب منه مكان آخر كثيرًا، تركت pcode فارغًا، ووضعت في alternatives أفضل ثلاثة مرشحين لتختار أنت من بينهم.

r = match("Gallabat")
r["pcode"], r["method"]                       # (None, 'ambiguous')
[(a["pcode"], a["name_en"]) for a in r["alternatives"]]
# [('SD12077', 'Basundah'), ('SD12083', 'Galabat Ash-Shargiah'), ('SD12078', 'Al Galabat Al Gharbyah - Kassab')]
const r = match("Gallabat");
[r.pcode, r.method];                          // [null, "ambiguous"]
r.alternatives.map((a) => [a.pcode, a.name_en]);
// [["SD12077", "Basundah"], ["SD12083", "Galabat Ash-Shargiah"], ["SD12078", "Al Galabat Al Gharbyah - Kassab"]]

Gallabat town lies on the boundary between two localities, so both are offered. Decide with your own knowledge of the data, and store your decision so the next run doesn't ask again.

تقع بلدة القلابات على الحد بين محليتين، ولذلك تظهر المحليتان معًا. اختر بينهما بحسب معرفتك ببياناتك، واحفظ اختيارك حتى لا يتكرر السؤال في المرة القادمة.

Maps with GeoPandasرسم الخرائط بمكتبة GeoPandas

With the [geo] extra, geo.states() and geo.localities() return GeoDataFrames in EPSG:4326 with the columns pcode, name_en, name_ar, level, parent_pcode and geometry. Join your data on pcode, never on names.

عند تثبيت الإضافة [geo] تُرجع geo.states() وgeo.localities() جداول GeoDataFrame بنظام الإحداثيات EPSG:4326، فيها الأعمدة pcode وname_en وname_ar وlevel وparent_pcode وgeometry. اربط بياناتك بها عبر pcode، لا عبر الأسماء.

from sudan_atlas import geo

states = geo.states(resolution="light")
states.merge(my_totals, on="pcode", how="left").plot(column="people", legend=True, missing_kwds={"color": "#d4d4d8"})
// GeoPandas is Python only. In JavaScript, use getFeature() with any mapping library
// (D3, Leaflet, MapLibre): every feature is plain GeoJSON with the same properties.

Use it in a web pageالاستخدام في صفحة ويب

No build step needed: import the package from jsDelivr. Boundary files are fetched from the same place when you first ask for them.

لا تحتاج إلى أي أدوات بناء: استورد الحزمة مباشرة من jsDelivr، وستُجلب ملفات الحدود من هناك أيضًا عند أول طلب.

<script type="module">
  import { match, getFeature } from "https://cdn.jsdelivr.net/npm/sudan-atlas@0.1/dist/index.js";
  console.log(match("Omdurmaan", { level: 2 }).pcode);   // "SD01006"
</script>
# In the browser, use the JavaScript package (switch the examples above to JavaScript).

Serve the boundary files yourselfاستضافة ملفات الحدود على خادمك

In Node and Python the files are read from the package itself. In a browser they come from jsDelivr unless you copy the package's data/ folder to your own server and point the package at it.

في Node وبايثون تُقرأ ملفات الحدود من داخل الحزمة. أما في المتصفح فتُجلب من jsDelivr، إلا إذا نسخت مجلد data/ من الحزمة إلى خادمك ووجّهت الحزمة إليه.

import { setDataUrl, getFeature } from "sudan-atlas";

setDataUrl("/static/sudan-atlas/");                 // your copy of node_modules/sudan-atlas/data/
const khartoum = await getFeature("SD01", "medium");
# Not needed in Python: get_feature() reads the files bundled with the package.

Without code: the map-makerدون برمجة: صانع الخرائط

The map-maker does all of this in your browser: open a CSV or Excel file, check the uncertain matches, then download a map and your file with P-codes added. Your file never leaves your device.

يؤدي صانع الخرائط كل ما سبق داخل متصفحك: افتح ملف CSV أو Excel، وراجع المطابقات غير المؤكدة، ثم نزّل الخريطة وملفك وقد أُضيفت إليه الرموز المكانية. ولا يغادر ملفك جهازك.

Reference:المرجع: Matcher

match() uses a shared matcher with the default settings. Create your own to change them.

تستخدم match() أداة مطابقة مشتركة بالإعدادات الافتراضية، ويمكنك إنشاء أداتك الخاصة إذا أردت تغييرها.

from sudan_atlas import Matcher

strict = Matcher(threshold=0.9, margin=0.08)
strict.match("Kornoi", state_hint="North Darfur", level=2)
import { Matcher } from "sudan-atlas";

const strict = new Matcher(undefined, { threshold: 0.9, margin: 0.08 });
strict.match("Kornoi", { stateHint: "North Darfur", level: 2 });

threshold (default 0.82) is the lowest score accepted as a match. margin (default 0.05) is how far ahead of the second place the best candidate must be; closer than that, the result is ambiguous.

threshold (القيمة الافتراضية 0.82) هي أدنى درجة تُقبل بها المطابقة. وmargin (القيمة الافتراضية 0.05) هي أقل فارق مقبول بين أفضل مرشح والذي يليه؛ فإن كان الفارق أصغر كانت النتيجة ambiguous.

Reference: P-codesالمرجع: الرموز المكانية

P-codes are the official codes from OCHA's Common Operational Datasets. SD is Sudan; a state adds two digits (SD15, Aj Jazirah); a locality adds three more (SD15034, Al Hasahisa). Join datasets on P-codes, never on names: names have many spellings, P-codes have one.

الرموز المكانية (P‑codes) هي الرموز الرسمية في مجموعات البيانات التشغيلية المشتركة التي يصدرها أوتشا. يرمز SD إلى السودان، ويضيف رمز الولاية رقمين (SD15 لولاية الجزيرة)، ويضيف رمز المحلية ثلاثة أرقام أخرى (SD15034 لمحلية الحصاحيصا). اربط بياناتك بالرموز لا بالأسماء: فللاسم صيغ كثيرة، أما الرمز فواحد.

How matching worksكيف تعمل المطابقة

  1. Normalise. Both the input and every known name become a matching key: Arabic letter forms are unified (أ إ آ → ا, ة → ه, ى → ي), diacritics and articles (Al-, El-, ال) are set aside, common transliteration differences are merged (ou/u, ei/ai), and words such as "locality" or "محلية" are dropped.
  2. Exact. The key is compared with the official English and Arabic names of every place.
  3. Known spellings. Then with more than a thousand reviewed spellings gathered from GeoNames, Wikidata, OpenStreetMap and humanitarian datasets.
  4. Fuzzy. Then with every name by similarity, which catches typos and new spellings.
  5. Decide. The best candidate is accepted only if it scores at least 0.82 and is at least 0.05 ahead of the next place. Otherwise you get the candidates and the decision is yours.
  1. التوحيد. يُحوَّل الاسم المُدخل، وكل اسم معروف، إلى مفتاح موحّد للمطابقة: تُوحَّد أشكال الحروف العربية (أ إ آ ← ا، ة ← ه، ى ← ي)، وتُتجاهل الحركات وأداة التعريف (Al-، El-، ال)، وتُعامل الفروق الشائعة في كتابة الأسماء بالحروف اللاتينية معاملة واحدة (ou/u، ei/ai)، وتُحذف كلمات مثل "locality" و"محلية".
  2. المطابقة التامة. يُقارن المفتاح أولًا بالاسمين الرسميين العربي والإنجليزي لكل مكان.
  3. الصيغ المعروفة. ثم بأكثر من ألف صيغة مراجَعة، جُمعت من GeoNames وويكي بيانات وOpenStreetMap ومن مجموعات البيانات الإنسانية.
  4. المطابقة التقريبية. ثم بجميع الأسماء حسب درجة التشابه، فتُلتقط الأخطاء الإملائية والصيغ الجديدة.
  5. القرار. لا يُقبل أفضل مرشح إلا إذا بلغت درجته 0.82 على الأقل، وتفوّق على المكان التالي بفارق 0.05 على الأقل. وإلا عُرض عليك المرشحون، والقرار لك.

The Python and JavaScript matchers share the same rules file and are tested against the same expected results, so they return identical answers.

تعتمد أداتا المطابقة في بايثون وجافاسكربت على ملف القواعد نفسه، وتُختبران على النتائج المتوقعة نفسها، ولذلك تعطيان الإجابة نفسها دائمًا.

How accurate it isما مدى دقته؟

On 299 real names taken from humanitarian datasets (IOM, UNHCR, OCHA, IPC and the US Census Bureau), each checked by hand:

اختبرنا أداة المطابقة على 299 اسمًا حقيقيًا من مجموعات بيانات إنسانية (المنظمة الدولية للهجرة، ومفوضية الأمم المتحدة لشؤون اللاجئين، وأوتشا، والتصنيف المرحلي المتكامل للأمن الغذائي، ومكتب الإحصاء الأمريكي)، وتحققنا من كل اسم يدويًا:

  • 94.9% matched to the right place first time
  • 99.6% had the right place among the top three
  • 0 matched to a wrong place: when it isn't sure, it asks
  • 94.9% من الأسماء رُبطت بمكانها الصحيح مباشرة
  • 99.6% من الأسماء كان مكانها الصحيح بين أول ثلاثة مرشحين
  • 0 أسماء رُبطت بمكان خاطئ: حين لا تكون الأداة متأكدة، تسألك

The full evaluation is in MATCHER_EVALUATION.md.

تفاصيل التقييم كاملة في MATCHER_EVALUATION.md (بالإنجليزية).
